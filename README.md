# The World in One Day

A six-story poster summarizing world news for Tuesday 24 November 2026. `render.py` builds the 1024 × 1024 PNG using Pillow and DejaVu Sans. The shipped `entry.png` is copied by `main.py` to `MAKEFUN_OUTPUT_DIR`, or `/output` by default; the runtime uses only Python's standard library and requires no network.
